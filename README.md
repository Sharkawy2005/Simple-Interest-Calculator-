# Simple Interest Calculator

A clean and straightforward tool for calculating simple interest based on principal amount, annual interest rate, and time period. 

## Features
* **Instant Calculations:** Computes total interest accrued and final balance in real time.
* **Flexible Timeframes:** Supports calculations across days, months, or years.
* **User-Friendly Interface:** Clean layout designed for quick, error-free inputs.

## Formula Used
$$I = P \times r \times t$$
* **I** = Total Interest
* **P** = Principal Amount
* **r** = Annual Interest Rate (in decimal)
* **t** = Time Period (in years)
